# PhoneNap pilot · V2.8 frozen

Open: `sketches/index.html`

## Tester instructions

1. Create PIN on first launch; use Settings for age band (3 / 4 / 5 / Prefer not to say).
2. Run a real nap with a child roughly ages 3–5.
3. After unlock, complete the optional check-in (or skip).
4. Use **Copy all** on the page to export the local feedback log when needed.

### Observation window (required for comparable data)

When answering **Did the child ask for the phone again?**:

- **Yes** only if they ask again within **five minutes** of the handoff.
- **No** if they do not ask within that window.

The UI does not enforce the five minutes — parents/testers must apply it consistently.

### What not to change

V2.8 is frozen. Do not add features or redesign flows unless a real session fails in a clear, repeated way.
